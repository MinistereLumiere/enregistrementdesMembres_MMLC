Configuration requise

Configurez Firebase pour démarrer votre application

Étape 1 — Créer un projet Firebase

  1. Allez sur console.firebase.google.com
  2. Créez un nouveau projet (ex : "ministere-maison-lumiere")
  3. Activez Authentication → méthode "Email/Mot de passe"
  4. Activez Firestore Database en mode production
  5. Dans Paramètres → Vos applications → Web, copiez la config

Étape 2 — Coller la configuration

Ouvrez ce fichier index.html dans un éditeur et remplacez le bloc FIREBASE_CONFIG par votre configuration.

const FIREBASE_CONFIG = {
  apiKey: "VOTRE_API_KEY",
  authDomain: "votre-projet.firebaseapp.com",
  projectId: "votre-projet",
  storageBucket: "votre-projet.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123:web:abc123"
};

Étape 3 — Premier compte admin

Une fois Firebase configuré :

  1. Dans la console Firebase → Authentication → Créez un utilisateur
  2. Dans Firestore, créez une collection users
  3. Ajoutez un document avec l'UID de l'utilisateur, contenant : 
    {
  "email": "admin@example.com",
  "nom": "Admin",
  "role": "admin",
  "createdAt": [timestamp]
}
  4. Rechargez cette page et connectez-vous

Étape 4 — Règles Firestore

Dans Firestore → Règles, collez ceci :

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isAuth() { return request.auth != null; }
    function isAdmin() {
      return isAuth() &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
    match /users/{userId} {
      allow read: if isAuth();
      allow write: if isAdmin();
    }
    match /{document=**} {
      allow read, write: if isAuth();
    }
  }
}

Hébergement Firebase : Une fois prêt, déployez avec firebase deploy --only hosting après avoir initialisé Firebase Hosting dans votre dossier.
